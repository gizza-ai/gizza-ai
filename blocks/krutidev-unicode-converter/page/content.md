## About Kruti Dev to Unicode Converter

This offline-capable tool allows you to convert text typed in the legacy Hindi **Kruti Dev 010** font layout into standardized **Unicode Devanagari** (often rendered using the Mangal font), and vice versa. 

Legacy fonts like Kruti Dev map Hindi characters directly onto standard English keyboard ASCII keys. This means the underlying text is stored as English characters (e.g., `esjk uke` translates to `मेरा नाम`), making it impossible to search, copy-paste to other devices, or read without installing the specific Kruti Dev font. Converting your text to Unicode transforms it into standard Devanagari character points that can be read on any modern smartphone, tablet, computer, or search engine without requiring any special fonts.

### Key Features
- **Bidirectional Conversion**: Seamlessly convert from Kruti Dev to Unicode, and Unicode back to Kruti Dev.
- **Synced Dual-Textareas**: Type, paste, or edit on either side, and watch the converted text update in real-time.
- **Smart Shift Algorithms**: Automatically handles complex Hindi character structures, including the positioning of *chhoti-i* (`ि`) matras and superscript *reph* (`र्`) marks.
- **100% Client-Side**: No data is sent to external servers. Your text remains secure on your machine.
- **One-Click Actions**: Quickly copy or clear text from either pane with one click.

## Frequently Asked Questions

<details>
<summary>What is Kruti Dev?</summary>

Kruti Dev is one of the most widely used legacy non-Unicode fonts for typing Hindi. It uses the Remington typewriter keyboard layout. Since it was created before Unicode was standardized, it maps Devanagari visual glyphs to standard Latin keyboard keys.

</details>

<details>
<summary>Why should I convert Kruti Dev to Unicode?</summary>

Unicode Devanagari is the global standard for representing Hindi text digitally. When you convert Kruti Dev to Unicode:
1. Your text becomes searchable on Google, Bing, and other search engines.
2. The text can be read on any device (Android, iOS, Windows, Mac, Linux) without installing additional fonts.
3. You can paste it into email, social media (Facebook, WhatsApp), and modern database systems.

</details>

<details>
<summary>Does this tool support Kruti Dev 011 and other versions?</summary>

Yes! The character mappings for Kruti Dev 010 and 011 are identical for standard Hindi typing, so this converter works perfectly for both.

</details>

<details>
<summary>How does the offline conversion work?</summary>

The conversion logic runs locally inside your browser using compiled WebAssembly. There are no server requests or external dependencies, ensuring lightning-fast performance and total privacy.

</details>
