## About this tool

The **Citation Generator** turns the details of a source into a correctly
formatted reference in **APA 7th**, **MLA 9th**, **Chicago 17th**, or
**Harvard** (author-date) style.
Type in whatever fields you have — author, title, year, journal or website
name, volume, issue, pages, URL, or DOI — pick a style, and copy the result.

Everything runs **locally in your browser**: no upload, no account, and your
references never leave your device.

### How it works

- **Authors** — separate multiple authors with a semicolon (`;`) or the word
  `and`. Write each name as `Family, Given` or `Given Family`. A single token
  with no space (for example `UNESCO`) is treated as an organization.
- **Container** — the larger work the source appears in: the **journal name**
  for an article, the **website name** for a web page, or the **book/anthology
  title** for a chapter. Leave it blank for a standalone work such as a whole
  book, and add a **publisher** instead.
- **DOI vs URL** — a DOI is preferred when present; the tool adds the
  `https://doi.org/` prefix for you.
- **Style differences** — APA uses author initials and sentence-case titles;
  MLA and Chicago use full given names and title-case headings, quote the
  title of a part-of-a-larger-work, and order the volume/issue/pages
  differently. The generator applies each style's conventions automatically.

### Notes

Output is plain text, so the *italics* the styles call for (journal and book
titles) are not rendered — apply them yourself after pasting. The tool formats
one source at a time and does not look up or invent missing details.
