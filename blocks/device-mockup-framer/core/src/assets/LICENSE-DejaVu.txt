DejaVuSansMono.ttf is part of the DejaVu Fonts project
(https://dejavu-fonts.github.io/), derived from the Bitstream Vera Fonts.

It is bundled here (embedded into the wasm via include_bytes!) so the
code-screenshot renderer never touches the host filesystem — the chat runtime
and the wasm sandbox have no font directory.
